A collection of modern, sleek, and high-performance desktop themes for [Playnite](https://playnite.link/).

🌐 **Official Showcase & Direct Downloads**: [https://playnite.goover.dev/](https://playnite.goover.dev/)

## Themes in this Suite

- **Penumbra Dawn**: Modern balanced dark theme with crisp slate tones and ambient accents.
- **Penumbra Night**: Deep immersion theme featuring vibrant teal highlights, expandable media tabs, and custom video controls.
- **Penumbra Blur**: Translucent frosted-glass aesthetic powered by ThemeModifier.

## Features

- **Smooth Scrolling**: Pixel-unit list virtualization (`VirtualizingPanel.ScrollUnit="Pixel"`) for stutter-free browsing.
- **Rich Plugin Ecosystem**: Out-of-the-box integration for DuplicateHider, BackgroundChanger, GameActivity, CheckDLC, ScreenshotsVisualizer, ReviewViewer, and themeExtras.
- **Library Banners**: Includes 124+ custom banners, including dedicated branding for Roberts Space Industries (Star Citizen).
- **Custom Media Controls**: Integrated video trailer player with play, pause, and mute triggers.
